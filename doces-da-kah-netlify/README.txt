# Doces da Kah — site para Netlify

Site estático responsivo, pronto para publicar no Netlify.

## Publicar
1. Extraia o arquivo ZIP.
2. Acesse https://app.netlify.com/drop
3. Arraste a pasta `doces-da-kah-netlify` (a pasta que contém `index.html`) para a área indicada.
4. O Netlify publicará o site e fornecerá um endereço `*.netlify.app`.

## Arquivos
- `index.html` — conteúdo e produtos
- `styles.css` — layout e aparência
